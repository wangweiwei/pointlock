## Bugs & feature requests

- **Bugs** — open a [bug report](.github/ISSUE_TEMPLATE/bug_report.yml). Please search existing issues first.
- **Features** — open a [feature request](.github/ISSUE_TEMPLATE/feature_request.yml). Note that changes to the Typed IR, the Provider SPI, the event vocabulary, or the projection protocol are design-governed — see [CONTRIBUTING](CONTRIBUTING.md).

## Security

Please do **not** file public issues for security vulnerabilities. See the
[security policy](SECURITY.md) for private reporting.
